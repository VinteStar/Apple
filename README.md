# Apple Anleitung:

Bildschirm über AirPlay kabellos übertragen

Mit Apple AirPlay kannst du den Bildschirm deines iPhones, iPads oder Macs kabellos auf das Smartboard übertragen. So lassen sich beispielsweise Präsentationen, Fotos, Videos und andere Inhalte direkt auf dem großen Bildschirm anzeigen.

# Schritt 1: Smartboard einschalten
Schalte das Smartboard ein und tippe auf Bildschirmfreigabe.

# Schritt 2: Verbindung vorbereiten
Stelle sicher, dass dein Apple Gerät mit dem Gäste Wlan verbunden ist.

# Schritt 3: Bildschirmübertragung öffnen

 Auf dem iPhone oder iPad:
 1. Wische von der oberen rechten Bildschirmecke nach unten, um das Kontrollzentrum zu öffnen.
 2. Tippe auf *„Bildschirmsynchronisierung“* (das Symbol mit den zwei überlappenden Rechtecken).

 Auf dem Mac:
 1. Öffne das Kontrollzentrum oben rechts in der Menüleiste.
 2. Klicke auf *„Bildschirmsynchronisierung“* oder *„Bildschirmspiegelung“*.

# Schritt 4: Smartboard auswählen
Wähle in der Liste das angezeigte Smartboard aus.

# Schritt 5: Verbindung bestätigen
Warte, bis die Verbindung hergestellt wurde.

# Schritt 6: Inhalte übertragen
Nach erfolgreicher Verbindung wird der Bildschirm deines Apple-Geräts auf dem Smartboard angezeigt. 
Du kannst nun beispielsweise Präsentationen öffnen, Bilder zeigen oder Apps verwenden.

Beim Mac kannst du, sofern angeboten, zwischen der Spiegelung des Bildschirms und der Verwendung des Smartboards als erweitertem Bildschirm wählen.

# Schritt 7: Verbindung beenden

Auf dem iPhone oder iPad:
1. Öffne erneut das Kontrollzentrum.
2. Tippe auf „Bildschirmsynchronisierung“.
3. Wähle „Synchronisierung stoppen“.

Auf dem Mac:
1. Öffne das Kontrollzentrum.
2. Wähle die Bildschirmspiegelung aus.
3. Trenne die Verbindung zum Smartboard.
